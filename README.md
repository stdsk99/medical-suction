# Medical Suction Repair Trainer

สื่อฝึกซ่อมและบำรุงรักษาเครื่องดูดทางการแพทย์ (portable electric suction) ของศูนย์การเรียนรู้เทคโนโลยีทางการแพทย์
เครื่องในแอปเป็นเครื่องจำลองทั่วไป เนื้อหาเขียนใหม่จากหลักการในคู่มือผู้ใช้และคู่มือซ่อมของเครื่องดูดหลายรุ่น (Medline Vac-Assist HCS7000, DeVilbiss Vacu-Aide QSU 7314, Aeros Instavac, Weinmann Accuvac Rescue) ไม่ได้คัดลอกภาพหรือตาราง

## โมดูล (เรียนตามลำดับ สอบท้ายโมดูลสุ่ม 5 จาก 8 ข้อ ผ่าน 4 ข้อ)

1. ภาพรวมการทำงาน – ทั้งเครื่องในภาพเดียว เส้นทางเสมหะและอากาศ 4 ระบบ แรงดันลบและหน่วย
2. ส่วนประกอบและเส้นทางลม – แตะชิ้นส่วนบนภาพตัด
3. การใช้งานสำหรับช่าง – บทเรียน ฝึกตั้งแรงดัน ตรวจก่อนใช้ มุมช่าง (`clin:sim`)
4. ด่านความปลอดภัย – สอบท้ายโมดูลต้องถูกครบ 5 ข้อ (`pass:5` ใน data/mquiz.js, `mqPass` ใน config และ Code.gs)
5. ตรวจรับเครื่อง (`accept`)
6. PM ตามรอบ (`pmplan`)
7. คู่มือวิเคราะห์อาการ + โจทย์ซ่อม 10 เคส โหมดเรียนรู้ (`learn:`) และโหมดสอบ (`exam:`)
8. ทดสอบหลังซ่อม (ฝึกตัดสินผล) + ลำดับขั้นตอนงาน 3 งาน (`order:`)
- สอบรวม 20 ข้อ (`quiz`) เปิดเมื่อผ่านครบ 8 โมดูล
- หน้า 3D (`3d/`) – Three.js r170 ดูทางลมและลูกลอย ฝึกถอดเปลี่ยน 6 งาน (ไม่นับเกณฑ์)

## โครงสร้างไฟล์

```
index.html          โครงหน้า
css/suction.css     ภาพเครื่องดูดและส่วนที่ต่างจากวิชาอื่น (style.css, svc.css ใช้ร่วมกับวิชาอื่น)
js/dia.js           ภาพตัดเครื่องดูด (SVG) ใช้ร่วมกันทุกโมดูล
js/app.js           โมดูล 1–2, 4, 7 (คู่มืออาการ) และการเปลี่ยนหน้า
js/learn.js         โหมดเรียนรู้ (ภาพเคลื่อนไหว)   js/sim.js  โหมดสอบ
js/tech.js          โมดูล 3   js/svc.js โมดูล 5–6   js/pm.js, js/order.js โมดูล 8   js/quiz.js สอบรวม
js/score.js, auth.js, cert.js, mgate.js   ระบบบัญชี คะแนน ใบรับรอง เรียนตามลำดับ (มาจากวิชาตู้อบ)
data/*.js           เนื้อหาทั้งหมด แก้ได้โดยไม่ต้องแตะโค้ด
3d/                 หน้า 3 มิติ (main.js โมเดล · data.js ใบงาน · task.js โหมดฝึกจากวิชาตู้อบ)
```

คะแนนเก็บในคีย์ localStorage ขึ้นต้น `sut-` และส่งเข้า Google Sheet "Med Center" ผ่าน Apps Script ตัวเดียวกับทุกวิชา (แอป `suction`)
